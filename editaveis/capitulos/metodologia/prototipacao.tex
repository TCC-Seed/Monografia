

Segundo \citeonline{vazquez2016engenharia}, a prototipação é um elemento essencial no desenvolvimento da experiência do usuário (UX), pois possibilita tanto a validação com os usuários quanto uma visão inicial do sistema.

Além disso, a prototipação também facilita a implementação dos requisitos, já que estes são diretamente incorporados ao protótipo, sendo extraídos do backlog do produto e representados nas telas \cite{vazquez2016engenharia}. Dessa forma, o protótipo desenvolvido para este projeto encontra-se disponível no Apêndice~\ref{apendice:prototipo}.
